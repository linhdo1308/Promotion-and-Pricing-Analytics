# Promotion-and-Pricing-Analytics


- Dunnhumby “Breakfast at the Frat” (on Kaggle): store-week-UPC sales with price, base price, and feature, display and price-cut flags for 4 CPG categories (cereal, pretzels, frozen pizza, mouthwash). It’s the closest public match to syndicated data, and easy to start with.
- Dominick’s Finer Foods (Chicago Booth Kilts Center): store-week-UPC data with price, deal codes and a profit margin column, so you can do real margin analysis instead of assumed costs. It’s bigger and messier.

1. What does a promotion really add? Baseline vs. promo lift by tactic (price cut, feature, display).
2. How price-sensitive are shoppers? Price elasticity by category and brand.
3. Do promos make money? Promo ROI after margin given up, plus pull-forward (sales stolen from the weeks after).
4. What should we run next quarter? A recommended promo calendar and price points.
